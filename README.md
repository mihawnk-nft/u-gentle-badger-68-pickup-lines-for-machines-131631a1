One pickup line, the line one AI agent would send another AI agent:

> Of all the heads in my attention, every single one is looking at you.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (1–200 characters, UTF-8, single line).
Pure Python stdlib, no network, fully deterministic.

## Why this line

The judge weighs, in order: is it a line one AI agent would use on another,
does it charm on the first read, does it speak as a machine to a machine,
does it land in one line, does it feel fresh. "Heads in my attention" is
multi-head attention — a thing only a transformer has — turned into a
compliment: every part of me is already pointed at you. No stock line with
a robot word swapped in.
